# Udemy Clone – Online Courses Website

## About the Project
A responsive online course website landing page inspired by Udemy, built using HTML and CSS. It displays course categories, recommended courses, popular courses, and learning topics in a clean and user-friendly layout.

## Features
- Navigation bar with search box
- Course category navigation
- Promotional banner
- Recommended and popular course sections
- Course cards with images, ratings, and prices
- Recommended learning topics
- Responsive design for desktop, tablet, and mobile
- Hover effects and smooth scrolling

## Technologies Used
- HTML5
- CSS3
- Google Fonts
- Unsplash Images
